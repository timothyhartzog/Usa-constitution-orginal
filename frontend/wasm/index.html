How to build the WASM bundle 
# 1. Build the binary archive (one-shot, ~11 MB)
cargo run --release --bin constitution-archive -- build

# 2. Build the WASM module (requires wasm-pack)
cargo install wasm-pack
wasm-pack build crates/constitution-wasm \
    --release --target web \
    --out-dir ../../frontend/wasm/pkg

# 3. Serve the repo and open this page
python3 -m http.server 8000
# → http://localhost:8000/frontend/wasm/

Until the pkg/ directory is built this page falls back to the JSON corpus and displays a notice — so the page itself is always functional.
